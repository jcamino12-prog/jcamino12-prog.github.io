Portfolio website scaffold

Files in the workspace root (d:\Python Demo):

- index.html — Home / featured projects
- about.html — About, skills, experience
- projects.html — Projects listing
- contact.html — Contact form (mailto fallback)
- styles.css — Site styles (dark theme)
- scripts.js — Small JS helpers (mobile nav, mailto)

Owner: Jonathan Camino

How to use

1. Open the workspace folder in VS Code.
2. Open index.html in the browser (right-click > Open with Live Server or double-click the file in the explorer).
3. Replace placeholder text, links, and project details with your own content.
4. If you want a live dev experience, install an HTTP server (e.g., Live Server extension) or serve with a simple static server.

Deploy to GitHub Pages

This site is a static HTML/CSS/JS project and is ready to be hosted on GitHub Pages.

1. Create a repository on GitHub and push these files to the repository's main branch (or a branch named gh-pages).
2. In the repository settings, enable GitHub Pages and select the branch to publish (usually main or gh-pages).
3. The site will be available at https://<your-github-username>.github.io/<repo-name>/ (or the user/organization site if you publish to the main branch of a repository named <your-github-username>.github.io).
